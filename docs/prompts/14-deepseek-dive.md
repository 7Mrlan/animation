# 潜入答案：独立生成提示词

```text
从空目录创建 React + TypeScript + Vite 动画演示，普通 CSS 与 SVG，不加动画库。
组件名 DeepSeekDive，各实例独立，提供 npm run dev/build。

画面为蓝白色、留白充足的圆角卡片。舞台约360×300，浅蓝水体占下半部。
使用 DeepSeek 官方 DeepSeek-LLM 仓库 images/logo.svg 的小鲸路径，
保存为本地素材并记录出处；裁切身体与尾巴，尾巴绕连接处独立摆动。
不加聊天窗口、旋转轨道或鼠标发光圈。

水面叠加不同相位的移动正弦波，一维弹簧采样传递冲击，
用连续贝塞尔曲线绘制分层水面、白色浪尖与水下流纹。
小鲸可直接拖拽，使用pointer capture，拖出目标后也可释放。
入水后摆尾、带出气泡与尾流，松手后沿曲线深潜、浅游和绕弯。
身体俯仰跟随速度，避免固定高度左右往返。

鲸跃先上浮蓄力并加快摆尾，再沿重力抛物线跃出水面；
身体随速度转动，落水产生大浪花，接回深潜。
首次巡游几秒后可以鲸跃，之后间隔约9–13秒再蓄力。
双击或空格主动触发，向上轻甩后松手也可触发。
在水面快速拖动时，按速度增大浪花、水滴数量和水面冲击，设置上限并清理过期粒子。

使用RAF与ref，避免每帧React setState；用useId隔离SVG ID，支持GitHub Pages子目录。
提供active/reduced属性、暂停恢复、重播、离屏和后台暂停。
暂停保存姿态与时钟，恢复不补算后台时间，卸载清理RAF、监听器、粒子与捕获。
静态模式不循环、不生成粒子，仍支持拖动和键盘摆放。
检查长期巡游不越界、无跳位、鲸跃反复落水、水波有界且衰减。
实际检查鼠标、触摸、键盘、窄屏和暂停重播，报告测试与构建结果。
```
