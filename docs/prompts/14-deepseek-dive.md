# 潜入答案：独立生成提示词

```text
从空目录创建 React + TypeScript + Vite 动画演示，普通 CSS 与 SVG，不加动画库。
组件名 DeepSeekDive，各实例独立，提供 npm run dev/build。

画面为蓝白色、留白充足的圆角卡片。舞台约360×300，浅蓝水体占下半部。
使用 DeepSeek 官方 DeepSeek-LLM 仓库 images/logo.svg 的小鲸路径，
保存为本地素材并记录出处；裁切身体与尾巴，尾巴绕连接处独立摆动。
不加聊天窗口、旋转轨道或鼠标发光圈。

水面叠加长涌浪、短风浪和浪群包络，一维弹簧采样传递局部冲击，
边缘吸收能量，阵风平滑增强后消退，偶尔吹起少量浪尖飞沫。
用平滑曲线绘制有深浅渐变的水体和局部浪峰反光，水下流纹、尾流和气泡裁切在水中。
鲸鱼保持等比，不随卡片宽高变形。转身使用七张关键姿态生成的 241 帧本地运动补间图集，按连续位置与角速度更新；不横向压缩到零，也不交叉淡化左右镜像。身体与尾部共享帧号，尾部绕对应姿态的连接点独立摆动，播放速度不依赖屏幕刷新率。
小鲸可直接拖拽，使用pointer capture，拖出目标后也可释放。
入水后摆尾、带出气泡与尾流，松手保留惯性，以受限加速度安排深潜、浅游和绕弯。
身体俯仰跟随速度，避免固定高度左右往返。

独处时根据水深、动量与空间随机选择推进后滑行、短冲回弯、贴水露背换气、下潜、探头、小幅侧身弧游、轻拍尾和短暂浮休；事件间有空档，不能排成固定表演。滑行需要已有动量，浮休必须先游到水面，再表现呼吸起伏、轻摆尾、漂移与Zzz，醒来先恢复推进；不能在水下静止装睡。动作进出与追逐接管保留位置、速度和姿态连续性。
鲸跃先下潜到准备区，再在水下蓄力、逐步加速，完全离水后沿重力抛物线运动；
身体随速度转动，限制空中横移，落水时按浸没比例增加浮力和水阻，减速后顺势潜游，不强制向上反弹。
起跳推力方向与惯性朝向分离，不能撞舞台侧壁或落水直接沉底。
首次巡游几秒后可以鲸跃，之后间隔约25–39秒再蓄力。高低跃由出水动量决定，首次接触水面产生一次冲击事件，按法向速度平方和接触面积分配水冠、传播波与扩散水纹；高跃余波更宽、更久。
双击或空格主动触发，蓄力和腾空时重复邀请不能重置动作；向上轻甩保留手势速度。
在水面快速拖动时统一按速度生成浪花和冲击，低速不喷溅，设置上限并复用过期粒子节点。

使用RAF与ref，避免每帧React setState；用useId隔离SVG ID，支持GitHub Pages子目录。
偶尔出现鱼虾群，每次随机时间、种类、数量、方向、深度与大小，运行时使用独立随机种子。
使用局部群游与预测逃逸，小鲸逐步加速追逐、实际嘴部接触后吞食并减速。
未被捕食的猎物必须游出卡片才移除，不能按时间突然消失；有活跃猎物时退出可中断的独处动作与自动蓄力，即使猎物还在入口也不能继续睡觉或新开自动鲸跃。鱼群分散时保持局部警戒和有限转向，威胁减弱后逐渐恢复对齐、聚合，不能瞬间传送归队。
提供active/reduced属性、暂停恢复、重播、离屏和后台暂停。
暂停保存姿态与时钟，恢复不补算后台时间，卸载清理RAF、监听器、粒子与捕获。
静态模式不循环、不生成粒子，仍支持拖动和键盘摆放。
检查长期巡游不触碰硬边界、无速度突变、鲸跃反复落水并继续下潜、水波有界且衰减，低刷新率不变慢。
实际检查鼠标、触摸、键盘、窄屏和暂停重播，报告测试与构建结果。
```
