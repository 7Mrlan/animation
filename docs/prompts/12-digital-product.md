# 12 数字产品的信息变化动画

```text
请从空目录创建一个可以运行的单卡片动画演示。你只需要这份规格，不需要原项目、截图或之前的对话。直接完成实现。

技术与交付
使用 React、TypeScript 和 Vite，Node.js 24，普通 CSS，系统字体。选择互相兼容的依赖版本，开启 TypeScript strict。除本提示词明确列出的素材或播放器外，不增加 UI 库、动画库或远程资源。
创建 package.json、HTML 入口、React 入口、演示页面、独立动画组件与对应 CSS。提供 npm run dev、npm run build、npm run preview 和简短 README。使用清楚的组件及类名前缀，允许同一页面放多个实例。
有文件和终端工具时实际创建文件、安装依赖并验证构建；只有文本输出能力时，按文件给出完整代码和运行命令，并说明哪些检查没有执行。

产品输入
产品默认“智能笔记与资料检索工具”。
要表达的特点默认“从几条分散记录中找到相关内容，并整理到一起”。
主要元素默认“便签、关键词、连接线和结果卡片”。
可以替换为日历、翻译、设计工具、文件管理或其他数字产品。只表达输入中明确提供的功能；产品变化时重新选择信息对象和变化过程。

先选择能看懂的信息动作
先用三行以内提出两个不同构思，每个写清初始信息、用户输入与最后结果。选择一个并直接实现。
动画必须让信息发生可追踪的变化，例如匹配词被标记、相关卡片归组、字符逐步替换、时间块重新安排。避免只让产品Logo旋转，或让几张无内容的玻璃卡片漂浮。
用visual continuity保持对应关系，初始出现的某张卡片在结果里仍能被认出来。位置变换时保留标题、颜色标记或编号，避免突然换成无关画面。

默认笔记工具的交互场景
舞台里放三张约96×66px的便签，初始错开位置与角度，各有简短可读标题和两条内容线。示例内容使用“旅行清单”“灵感草稿”“周末安排”，标签分别包含旅行、灵感或计划等关键词。
舞台底部提供三个真实按钮“旅行”“灵感”“计划”。点击或键盘激活后，在本地示例数据中匹配标签，不调用AI接口，也不伪装成真实网络搜索。
0至180ms，选中关键词下方画出细线，未选词保持可读。
180至450ms，相关便签上的词高亮，使用淡色背景和SVG描线提示，其他便签透明度降低到0.45。
450至900ms，相关便签沿清楚的短路径移动到前方结果区并整齐展开。路径最大位移80px，旋转收束到0deg，不穿过重要文字。
900至1250ms，结果卡片上的内容线以80ms交错显现，出现简短“已找到相关记录”的反馈。随后保持结果，等待下一次输入。
切换关键词时，先撤销上一轮临时标记，再从当前姿态平滑过渡到下一组结果。提供“重置”把便签放回初始位置。没有匹配时展示明确的空结果静态提示，不能一直转圈。

技术与术语
使用React状态保存query、matchedIds和动画阶段；用稳定key维持信息对象身份。CSS transition适合在确定位置间移动，复杂路径再用RAF插值。不要每次查询都随机生成新的卡片坐标。
用SVG path和stroke-dashoffset做连接或下划线揭示，用opacity表达其他信息暂时退后，用stagger安排内容线出现。定位与缩放放在不同父子层，避免transform相互覆盖。
有限状态可以是idle、matching、organizing、result、empty。用户在中途改变关键词时，要取消旧调度；最终结果必须对应最后一次输入。
暂停只停止装饰性过渡，关键词查询和可访问文本仍要更新；暂停期间可以直接显示最新的最终结果布局。
全部示例数据写在本地，注明这是交互演示。不要加入账号、收费或服务端请求。页面上的实现术语留在README，产品画面只显示用户能理解的词。

视觉方向
页面背景#f5f5fa，外卡片最大宽420px、24px圆角、10px内边距、白底与细边。舞台高300px，背景#f0eff9，卡片白色，主文字#384053，辅助文字#8990a3，重点颜色#8b7ec9，匹配高亮#e9e3ff。
便签边框低对比度，阴影随前后层级轻微变化；结果区边缘清楚，不用大面积模糊遮挡文字。320px视口下可减少同时显示的细节，但关键词按钮必须完整可操作。

本任务的验收重点
用户能追踪哪条记录被选中，以及它去了哪里。依次快速切换三个关键词，结果始终匹配最后一次输入。键盘操作、空结果、重置、暂停后继续都成立，静态模式直接显示最终布局且仍可查询。

播放与可访问性
在舞台左下角放两个独立按钮，分别控制暂停或继续、从头重播。按钮尺寸至少 32px，有中文 aria-label 和清晰的键盘焦点，按钮自身不要跟随内部图形运动。
初始进入页面即可看到完整构图。使用 IntersectionObserver 观察舞台，露出比例达到 0.08 时才允许自动播放，并结合 document.hidden 和手动暂停状态共同控制。切到后台或离屏后停止主要循环，回来时只在手动暂停未开启的情况下恢复。
CSS 动画通过 animation-play-state 暂停，覆盖普通元素和伪元素；JS 时间轴取消 RAF；播放器使用自身暂停接口。恢复时重置上一帧时间戳，避免把后台停留时间算进动画。
监听 prefers-reduced-motion。开启时停止装饰性循环与跟随位移，展示清楚的静态构图；必要的展开或切换可以立即完成。任何 Effect 都要清理监听器、观察器和待执行的回调，确保 React StrictMode 的重复创建与清理安全。

验证同页两个实例互不影响，卸载后没有继续运行的时间轴或播放器。运行 npm run build，报告执行结果；无法运行的检查写明未执行。最后用短说明解释关键帧、坐标与交互之间的关系。
```
