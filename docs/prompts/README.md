# 给陌生 AI 的动画生成提示词

这里有两组可单独使用的提示词。第 01 至 09 份从零生成已有动画，第 10 至 13 份根据新产品构思动画。打开对应文件，把完整文本块复制到新的 AI 对话即可，不需要原项目源码或其他章节。

只想拿一份通用模板，先选[第 10 份产品创意生成器](10-product-idea-generator.md)，替换产品名称和希望强调的特点。

## 让动作来自产品特点

产品名称以外，再写一句希望观众记住的特点，创意会更容易落到具体动作上。

| 产品信息                 | 可以发展的动作                 | 可用的技术术语                                              |
| ------------------------ | ------------------------------ | ----------------------------------------------------------- |
| 有可打开的盖子或折叠结构 | 打开后露出内容，部件依次就位   | hinge 铰接、reveal 显露、stagger 交错                       |
| 处理某种材料             | 大块变细、颜色混合、液面平稳   | clipPath 裁切、particle motion 粒子运动、mask 遮罩          |
| 整理或检索信息           | 标记关键词，把相关对象归到一起 | highlight 高亮、grouping 归组、visual continuity 对象连续性 |
| 表达任务进度             | 图形随真实进度变化，完成时确认 | progress-driven animation 进度驱动、draw-on 描线            |
| 需要收纳或配对           | 先分开，再吸附到各自位置       | snap 吸附、settle 收束、overlap 重叠运动                    |

先确定“用户触发了什么，哪个物件发生变化，最后得到什么反馈”，再选择漂浮、光晕或回弹作辅助。如果画面去掉产品名以后完全看不出用途，就让 AI 重新设计主动作，而不只是增加装饰。

## 一份提示词就是一次完整任务

直接复制一份即可，不必先拼接公共前言。每份都重复写入运行环境、卡片外观和播放要求，方便单独交给没有上下文的 AI。它会收到明确的尺寸、颜色、时长和坐标公式，还会知道该输出哪些文件，以及怎样检查结果。

默认结果是一个 React、TypeScript、Vite 单卡片演示，包含暂停、重播、离屏暂停和减少动态效果。前九份中有八份可以用文本提供的图形规则或 SVG 直接生成。Duo 的动作来自现成 Lottie 数据，提示词内附有两个固定版本的素材地址、文件名和校验值；它需要能取得这两份素材。后四份的默认案例都由代码绘制图形，不要求外部图片。

若要做整套画廊，可以在同一次任务中提交九份规格，并补充“把这些组件放进同一个项目，外卡片和播放控制共用，内部动画保持独立”。每张动画的细节仍以各自完整规格为准。

## 这些规格怎样使用

前九份的数值按学习项目的动画整理，并明确处理首次延迟、同一属性的动画覆盖、多实例和清理行为。后四份是新动画的生成模板，其中的默认案例属于待实现的设计规格。阅读代码的逐章教程保留在[学习手册](../learning/README.md)，需要理解术语时查看[术语表](../learning/11-motion-vocabulary.md)。

生成后的代码仍应按各提示词中的验收项检查。构建通过只能说明相应构建步骤成功，动画路径、交互和静态模式还需要实际观察。
