# 03 星光慢行的独立生成提示词

复制下面整个文本块，即可交给没有项目上下文的 AI。尺寸、图形、运动和交付要求都在块内。

```text
请从空目录创建一个可以运行的单卡片动画演示。你只需要这份规格，不需要原项目、截图或之前的对话。直接完成实现。

技术与交付
使用 React、TypeScript 和 Vite，Node.js 24，普通 CSS，系统字体。选择互相兼容的依赖版本，开启 TypeScript strict。除本提示词明确列出的素材或播放器外，不增加 UI 库、动画库或远程资源。
创建 package.json、HTML 入口、React 入口、演示页面、独立动画组件与对应 CSS。提供 npm run dev、npm run build、npm run preview 和简短 README。使用清楚的组件及类名前缀，允许同一页面放多个实例。
有文件和终端工具时实际创建文件、安装依赖并验证构建；只有文本输出能力时，按文件给出完整代码和运行命令，并说明哪些检查没有执行。
将独立动画组件命名为 GeminiOrbit。

目标画面
制作一张淡紫色星轨卡片。中央有蓝紫粉渐变的四尖星，两条带小圆点的椭圆轨道以相反方向慢慢转动，两个小星点错峰明灭。这个动画不需要指针跟随。

技术与图形
使用 React、内联 SVG、普通 CSS keyframes、伪元素和 useId。所有图形直接生成，不加载图片、图标库或外部素材。
SVG viewBox为0 0 160 160。四尖星路径为
M80 5C91 48 112 69 155 80C112 91 91 112 80 155C69 112 48 91 5 80C48 69 69 48 80 5Z
用左下到右上的 linearGradient 填充，三个色标依次为 #4888ee、offset0.5的#7e78ee、offset1的#dd85aa。每个实例用唯一ID并通过 url(#id)引用渐变，避免多个组件互相串色。

卡片外观
页面背景 #f6f7f9。外卡片最大宽376px，窄屏左右留16px，白底、21px圆角、8px内边距和细白边。阴影为0 1px 2px #23332a08、0 16px 32px -24px #23332a24。
舞台高258px、宽100%、圆角15px，背景为 radial-gradient(ellipse at 45% 55%,#e2e3ff 0%,#f0effe 40%,#f7f7fc 75%)。下方标题“星光慢行”，16px；英文“A quiet constellation”，10px、#a0a7a2。角落标注 NO. 03 与“CSS 循环”。
主星盒子105×105px，left50%、top46%，以自身一半宽高居中，投影为0 12px 24px #7776d732。
内轨道190×96px，外轨道240×146px，都以left50%、top46%为中心，边框1px #b2a9e93d，圆角50%。外圈额外opacity0.6。
每条轨道自身的 `::after` 画7px圆点，颜色 #ab9ae0，位置left19%、top8%，附淡白光晕。圆点跟父轨道旋转，不能固定在舞台上。
星点一为22px，颜色#9181d4，left19%、bottom25%；星点二为15px，right23%、top20%。可用内联小星形或字符✦，默认字体缺少字符时改用SVG。

运动规格
主星的7s ease-in-out循环，0%与100%为 translate(-50%,-50%) rotate(-6deg) scale(0.97)，50%为 translate(-50%,-57%) rotate(6deg) scale(1.05)。这里位移百分比以星形盒子为参考，纵向额外位移约7.35px。
两条轨道都使用18s linear无限循环，从 translate(-50%,-50%) rotate(-30deg) 到 translate(-50%,-50%) rotate(330deg)。内圈正向，外圈reverse，首尾相差一整圈。
轨道椭圆本体和它上面的圆点一起转动，不需要计算一个点在静止椭圆上的运动方程。
两个小星点都用4s ease-in-out，0%与100%为opacity0.35、scale0.7，50%为opacity1、scale1.1。第二个设置-2s negative delay，从周期中途开始，初始就与第一个错相。
把定位与运动合在完整 transform 中，或者用父层居中、子层运动。避免关键帧漏写居中位移导致星形跳开。

本动画额外验收
两条轨道确实反向完整旋转，星形浮动不改变其中心水平位置。首次暂停加载也能看见主星。两个实例同时显示时渐变各自正确。重播后星点仍保持错相关系。

播放与可访问性
在舞台左下角放两个独立按钮，分别控制暂停或继续、从头重播。按钮尺寸至少 32px，有中文 aria-label 和清晰的键盘焦点，按钮自身不要跟随内部图形运动。
初始进入页面即可看到完整构图。使用 IntersectionObserver 观察舞台，露出比例达到 0.08 时才允许自动播放，并结合 document.hidden 和手动暂停状态共同控制。切到后台或离屏后停止主要循环，回来时只在手动暂停未开启的情况下恢复。
CSS 动画通过 animation-play-state 暂停，覆盖普通元素和伪元素；JS 时间轴取消 RAF；播放器使用自身暂停接口。恢复时重置上一帧时间戳，避免把后台停留时间算进动画。
监听 prefers-reduced-motion。开启时停止装饰性循环与跟随位移，展示清楚的静态构图；必要的展开或切换可以立即完成。任何 Effect 都要清理监听器、观察器和待执行的回调，确保 React StrictMode 的重复创建与清理安全。

完成后的验收
检查 320px、768px、1440px 宽度，页面没有横向滚动，标题和按钮不被动画遮住。分别检查首次加载、循环接缝、暂停继续、重播、离屏返回和静态模式。
验证同页两个实例互不影响，卸载后没有继续运行的时间轴或播放器。运行 npm run build，报告执行结果；无法运行的检查写明未执行。最后用短说明解释关键帧、坐标与交互之间的关系。
```
