# 11 实体商品的结构与材料动画

这是一份从产品特点产生新创意的完整提示词。可以替换块内的产品输入；不替换也能按默认案例直接生成。

```text
请从空目录创建一个可以运行的单卡片动画演示。你只需要这份规格，不需要原项目、截图或之前的对话。直接完成实现。

技术与交付
使用 React、TypeScript 和 Vite，Node.js 24，普通 CSS，系统字体。选择互相兼容的依赖版本，开启 TypeScript strict。除本提示词明确列出的素材或播放器外，不增加 UI 库、动画库或远程资源。
创建 package.json、HTML 入口、React 入口、演示页面、独立动画组件与对应 CSS。提供 npm run dev、npm run build、npm run preview 和简短 README。使用清楚的组件及类名前缀，允许同一页面放多个实例。
有文件和终端工具时实际创建文件、安装依赖并验证构建；只有文本输出能力时，按文件给出完整代码和运行命令，并说明哪些检查没有执行。

产品输入
产品默认“无线耳机与收纳盒”。
要强调的体验默认“打开即用，收纳整齐，声音有空间感”。
材质默认“暖白色哑光外壳、深灰接缝、少量薄荷绿指示灯”。
输入可以替换为咖啡杯、香水瓶、相机、鞋子或其他实物。产品改变时，要从新物件的结构和使用动作重新设计，不能保留不相关的耳机动作。

设计方法
先找产品可发生相对运动的部分，例如盖子、按钮、抽屉、纸张或柔软部件，再决定一个能展示用途的操作。先用简短描述给出两个构思，选择一个并直接写出可运行实现。
用material cues表达材质。哑光可以采用低对比度渐变和柔和边缘，玻璃可以用高光轮廓与内部裁切，纸张则用薄边与小幅弯折。不要为了立体感让整件商品不停绕Y轴旋转。
用overlap重叠运动，让不同部件错开80至140ms；用settle收束，主要动作结束后只有一个很小的回落。最大回弹不超过主要位移的15%，避免像橡皮玩具。
给出开始姿态、操作中的关键姿态和完成后的姿态，明确部件的旋转轴与遮挡关系。若使用伪三维，使用CSS perspective与transform-origin，并处理背面与前后顺序。

默认耳机的完整方向
画一个约164×108px的收纳盒，下盖与顶盖分成两个元素。下盖圆角32px，顶盖以靠后的接缝为旋转轴；盒内放两只简化耳机，使用内联SVG绘制外壳和短柄。闭合时耳机在盒内，不能穿过盖子显示。
采用用户触发的一次性微剧情，hover进入、键盘激活或触摸点击均可触发，默认待机保持闭合静态。
0至220ms为预备，指示灯亮起，盒体只下沉1px。
220至520ms顶盖打开到约55deg，同时让内腔露出；限制透视程度，确保轮廓仍清楚。
450至800ms两只耳机依次上移，目标位移12px与16px，开始时间相差100ms。到达目标前可超出2px，再轻轻回落。
800至1500ms出现两组声波弧线，从耳机旁向外延伸并淡出。用SVG path与stroke-dasharray描线，两组错开120ms，幅度不超过舞台宽度的四分之一。
1500至1850ms耳机落回内腔，1850至2200ms顶盖闭合，指示灯变暗，完成一轮。允许在声音出现时停留一小段，但总剧情不超过3秒。
如果用户再次触发，按明确策略重播或等当前轮结束，不要叠加两个开盖过程。悬停停留不应无限重复主剧情，离开再进入才触发下一轮。

视觉与技术
使用React、TypeScript、普通CSS与内联SVG。优先用transform和opacity改变姿态，开合结构用父子层分离。用一个状态机描述closed、opening、playing、closing，所有退出与重播都清理旧的调度。
页面背景#f4f6f5，外卡片最大宽400px、白底、24px圆角、10px内边距。舞台高280px，使用#e9f1ed到#f7faf8的柔和渐变，内部物件留出至少24px安全空间。主体暖白#f8f7f3，接缝#adb7b2，薄荷强调#8cb9a0。
下方用产品名称和短句说明，不加入价格、购买按钮或真实设备连接状态。允许显示小型“开盒试听”交互按钮，音效不是必需条件，不自动播放音频。
使用几何图形表达产品，不要求外部图片或3D模型。产品换成别的物件时，保留结构动作、材质区分和清楚复位这些方法，重新给出匹配物件的尺寸与时间表。

本任务的验收重点
检查盖子和内腔遮挡是否正确，耳机是否沿合理路径出入，声波是否来自耳机而非凭空出现。短时间内反复进入、离开和点击时，图形仍能回到一个确定姿态。静态模式保留能看清产品结构的完成姿态。

播放与可访问性
在舞台左下角放两个独立按钮，分别控制暂停或继续、从头重播。按钮尺寸至少 32px，有中文 aria-label 和清晰的键盘焦点，按钮自身不要跟随内部图形运动。
初始进入页面即可看到完整构图。使用 IntersectionObserver 观察舞台，露出比例达到 0.08 时才允许自动播放，并结合 document.hidden 和手动暂停状态共同控制。切到后台或离屏后停止主要循环，回来时只在手动暂停未开启的情况下恢复。
CSS 动画通过 animation-play-state 暂停，覆盖普通元素和伪元素；JS 时间轴取消 RAF；播放器使用自身暂停接口。恢复时重置上一帧时间戳，避免把后台停留时间算进动画。
监听 prefers-reduced-motion。开启时停止装饰性循环与跟随位移，展示清楚的静态构图；必要的展开或切换可以立即完成。任何 Effect 都要清理监听器、观察器和待执行的回调，确保 React StrictMode 的重复创建与清理安全。

完成后的验收
检查 320px、768px、1440px 宽度，页面没有横向滚动，标题和按钮不被动画遮住。分别检查首次加载、动作复位、暂停继续、重播、离屏返回和静态模式；存在循环时再检查首尾接缝。
验证同页两个实例互不影响，卸载后没有继续运行的时间轴或播放器。运行 npm run build，报告执行结果；无法运行的检查写明未执行。最后用短说明解释关键帧、坐标与交互之间的关系。
```
