# 06 讯息涟漪的独立生成提示词

```text
请从空目录创建一个可以运行的单卡片动画演示。你只需要这份规格，不需要原项目、截图或之前的对话。直接完成实现。

技术与交付
使用 React、TypeScript 和 Vite，Node.js 24，普通 CSS，系统字体。选择互相兼容的依赖版本，开启 TypeScript strict。除本提示词明确列出的素材或播放器外，不增加 UI 库、动画库或远程资源。
创建 package.json、HTML 入口、React 入口、演示页面、独立动画组件与对应 CSS。提供 npm run dev、npm run build、npm run preview 和简短 README。使用清楚的组件及类名前缀，允许同一页面放多个实例。
有文件和终端工具时实际创建文件、安装依赖并验证构建；只有文本输出能力时，按文件给出完整代码和运行命令，并说明哪些检查没有执行。
将独立动画组件命名为 TelegramSignal。

目标画面
制作一张浅蓝色通信动画卡。中央有一部小手机，里面的三条消息按顺序变清晰；手机轻轻摆动，左右两枚信号圈呼吸。完全使用CSS和DOM绘制，不需要图标、图片或外部素材。

技术与结构
使用CSS伪元素或span绘制手机、顶部缺口、三条消息和两个圆环。手机是消息的定位父元素，手机浮动时消息整体跟随。消息自身只改变水平偏移和透明度。React只管理播放按钮与可见性，不使用JS计时器轮流显示消息。

卡片外观
页面背景#f6f7f9。外卡片最大宽376px，窄屏左右留16px，白底、圆角21px、内边距8px、细白边，阴影0 1px 2px #23332a08及0 16px 32px -24px #23332a24。
舞台高258px、宽100%、圆角15px、overflow hidden，背景linear-gradient(135deg,#e7f6fb,#f7fcff)，主色#348caf。下方标题“讯息涟漪”，16px；英文“A signal in the air”，10px、#a0a7a2。角落标NO. 06和“CSS 循环”。
手机65×112px，位于舞台中心，用translate(-50%,-50%)居中，圆角14px、2px主色边框、#ffffffb8背景、0 14px 22px #3286aa20投影。顶部缺口26×5px，top5px、水平居中，主色opacity0.42、圆角4px。
三条消息分别写+1、SMS、OK，高16px，左右各距手机8px，top依次28px、51px、74px，内边距3px 5px，5px圆角，背景#d6f0fa，7px文字#2f7f9d。
圆环A为35×35px，舞台left15%、top20%；圆环B为54×54px，right8%、bottom14%。均为1px主色边框、50%圆角。

手机浮动
周期4s，ease-in-out，无限循环。0%和100%为translate(-50%,-50%) rotate(-7deg)，50%为translate(-50%,-54%) rotate(-2deg)。这里-54%相对于手机自身高度，额外上移约4.48px。

消息交错
三条消息共享3.5s ease-in-out关键帧。0%、20%、100%为opacity0.35、translateX(4px)，45%、75%为opacity1、translateX(0)。从20%到45%渐入，从75%到100%退回，消息始终保留淡淡轮廓。
分别设置delay为0、0.8s、1.6s，构成stagger交错。首次正延迟等待期间也要应用起始关键帧，可用animation-fill-mode backwards；不要让后两条消息先完整显示再突然变暗。
延迟只决定起始相位，不为每一轮额外加入一段等待。保持同一组关键帧，方便调整节奏。

信号圈
周期3.2s、ease-in-out。0%和100%为scale0.85、opacity0.12，50%为scale1.18、opacity0.35。第二圈延迟1.2s，并处理等待初态。
这是往返的pulse呼吸，缩小后再放大，不做永远向外扩散的雷达波，也不把整个手机替换成图片动画。

本动画额外验收
第一次加载前两秒，消息按+1、SMS、OK的次序开始变化；后续循环保持错相。手机、消息和圆环各自的周期能同时运行。暂停必须连伪元素与消息一起停止，静态模式保留手机和三条可读消息。

播放与可访问性
在舞台左下角放两个独立按钮，分别控制暂停或继续、从头重播。按钮尺寸至少 32px，有中文 aria-label 和清晰的键盘焦点，按钮自身不要跟随内部图形运动。
初始进入页面即可看到完整构图。使用 IntersectionObserver 观察舞台，露出比例达到 0.08 时才允许自动播放，并结合 document.hidden 和手动暂停状态共同控制。切到后台或离屏后停止主要循环，回来时只在手动暂停未开启的情况下恢复。
CSS 动画通过 animation-play-state 暂停，覆盖普通元素和伪元素；JS 时间轴取消 RAF；播放器使用自身暂停接口。恢复时重置上一帧时间戳，避免把后台停留时间算进动画。
监听 prefers-reduced-motion。开启时停止装饰性循环与跟随位移，展示清楚的静态构图；必要的展开或切换可以立即完成。任何 Effect 都要清理监听器、观察器和待执行的回调，确保 React StrictMode 的重复创建与清理安全。

完成后的验收
检查 320px、768px、1440px 宽度，页面没有横向滚动，标题和按钮不被动画遮住。分别检查首次加载、循环接缝、暂停继续、重播、离屏返回和静态模式。
验证同页两个实例互不影响，卸载后没有继续运行的时间轴或播放器。运行 npm run build，报告执行结果；无法运行的检查写明未执行。最后用短说明解释关键帧、坐标与交互之间的关系。
```
