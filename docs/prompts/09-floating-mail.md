请从空目录创建一个可以运行的单卡片动画演示。你只需要这份规格，不需要原项目、截图或之前的对话。直接完成实现。

技术与交付
使用 React、TypeScript 和 Vite，Node.js 24，普通 CSS，系统字体。选择互相兼容的依赖版本，开启 TypeScript strict。除本提示词明确列出的素材或播放器外，不增加 UI 库、动画库或远程资源。
创建 package.json、HTML 入口、React 入口、演示页面、独立动画组件与对应 CSS。提供 npm run dev、npm run build、npm run preview 和简短 README。使用清楚的组件及类名前缀，允许同一页面放多个实例。
有文件和终端工具时实际创建文件、安装依赖并验证构建；只有文本输出能力时，按文件给出完整代码和运行命令，并说明哪些检查没有执行。
将独立动画组件命名为 FloatingMail。

目标画面
制作一张浅灰蓝色信封动画卡。中央信封略向左倾，前方右侧叠着一枚向右倾的白色标签，写“✦ Hello, world”。信封向上浮时标签略向下移，两张纸呈现轻轻分开的节奏。

技术与结构
使用React和普通CSS，DOM仅需舞台、信封主体、标签。用`::before`与`::after`两个伪元素拼出信封的上折角和下封口，不使用图片、SVG素材、图标库或JS逐帧动画。React只管理暂停、重播和可见性状态。

卡片外观
页面背景#f6f7f9。外卡片最大宽376px，窄屏左右留16px，白底、21px圆角、8px内边距、细白边。阴影为0 1px 2px #23332a08和0 16px 32px -24px #23332a24。
舞台宽100%、高258px、15px圆角，背景radial-gradient(ellipse at center,#e8edf9,#f6f8fc)，使用grid place-items center，position relative和overflow hidden。下方标题“一封轻盈的信”，16px；英文“Something good is coming”，10px、#a0a7a2。角落标NO. 09与“CSS 循环”。

信封几何
主体170×94px，11px圆角，1px #ccd5e3边框，底色#e2e9f4，阴影0 10px 20px #30476018。主体position relative并overflow hidden，基础旋转-6deg，变换原点居中。
上折角为124×124px方块，left22px、top-82px，旋转45deg，8px圆角，底色#f3f6fb，1px #ccd5e3边框。
下封口同样124×124px，left22px、top48px，旋转45deg，8px圆角，底色#fafcff，1px #dae1ec边框。它在上折角之后绘制。
两个完整方块的大部分被主体裁切，只留下组成折线的斜边。不要把伪元素放到舞台坐标系，也不要通过嵌套图片代替这段结构。

标签几何
标签绝对定位于舞台top=calc(50% + 15px)、left=calc(50% + 14px)，白色背景，1px #e1e6ef边框，8px圆角，10px内边距，12px文字#405574。星形与文字之间6px间距，阴影0 4px 10px #0000000a，基础旋转5deg。标签绘制在信封前面。

反向浮动
信封与标签都使用5s ease-in-out无限循环，0%与100%相同。
信封起终点为translateY(0) rotate(-6deg)，50%为translateY(-7px) rotate(-3deg)。
标签起终点为translateY(0) rotate(5deg)，50%为translateY(3px) rotate(8deg)。
这是counter-motion反向位移，信封上移7px时标签下移3px，保持同周期。不要把标签变成信封的运动子元素，否则标签会额外继承信封位移，改变相对动作。
把静态基础角度放在普通样式中，关键帧也明确写完整角度。关闭动画后依然是一封倾斜的信与一枚倾斜标签，不会全部摆正或消失。

本动画额外验收
不用网络图片也能看出信封折角和封口。两个方块被正确裁切，标签在前方。观察一轮5s，信封和标签的纵向运动方向相反，循环接缝没有跳位。按钮命中区域保持稳定，窄屏不裁掉标签文字。

播放与可访问性
在舞台左下角放两个独立按钮，分别控制暂停或继续、从头重播。按钮尺寸至少 32px，有中文 aria-label 和清晰的键盘焦点，按钮自身不要跟随内部图形运动。
初始进入页面即可看到完整构图。使用 IntersectionObserver 观察舞台，露出比例达到 0.08 时才允许自动播放，并结合 document.hidden 和手动暂停状态共同控制。切到后台或离屏后停止主要循环，回来时只在手动暂停未开启的情况下恢复。
CSS 动画通过 animation-play-state 暂停，覆盖普通元素和伪元素；JS 时间轴取消 RAF；播放器使用自身暂停接口。恢复时重置上一帧时间戳，避免把后台停留时间算进动画。
监听 prefers-reduced-motion。开启时停止装饰性循环与跟随位移，展示清楚的静态构图；必要的展开或切换可以立即完成。任何 Effect 都要清理监听器、观察器和待执行的回调，确保 React StrictMode 的重复创建与清理安全。

完成后的验收
检查 320px、768px、1440px 宽度，页面没有横向滚动，标题和按钮不被动画遮住。分别检查首次加载、循环接缝、暂停继续、重播、离屏返回和静态模式。
验证同页两个实例互不影响，卸载后没有继续运行的时间轴或播放器。运行 npm run build，报告执行结果；无法运行的检查写明未执行。最后用短说明解释关键帧、坐标与交互之间的关系。
