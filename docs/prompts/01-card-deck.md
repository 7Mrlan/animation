# 01 层叠之间的独立生成提示词

复制下面整个文本块，即可交给没有项目上下文的 AI。尺寸、图形、运动和交付要求都在块内。

```text
请从空目录创建一个可以运行的单卡片动画演示。你只需要这份规格，不需要原项目、截图或之前的对话。直接完成实现。

技术与交付
使用 React、TypeScript 和 Vite，Node.js 24，普通 CSS，系统字体。选择互相兼容的依赖版本，开启 TypeScript strict。除本提示词明确列出的素材或播放器外，不增加 UI 库、动画库或远程资源。
创建 package.json、HTML 入口、React 入口、演示页面、独立动画组件与对应 CSS。提供 npm run dev、npm run build、npm run preview 和简短 README。使用清楚的组件及类名前缀，允许同一页面放多个实例。
有文件和终端工具时实际创建文件、安装依赖并验证构建；只有文本输出能力时，按文件给出完整代码和运行命令，并说明哪些检查没有执行。
将独立动画组件命名为 CardDeck。

目标画面
制作一组有纸张厚度感的四张彩色卡片。它们叠放在舞台中央，前卡停留片刻后从左边抽出、下沉，再从后面回到卡堆。鼠标进入或键盘聚焦时，四张卡舒展成两行两列；触摸点击也能切换展开。文字仅使用 Form、Light、Space、Motion，没有商品或价格。

卡片外观
页面背景 #f6f7f9。外卡片最大宽 376px，窄屏左右各留 16px，白色背景、21px 圆角、8px 内边距和细白边。外阴影使用 0 1px 2px #23332a08、0 16px 32px -24px #23332a24。舞台宽 100%、高 258px、15px 圆角，背景为从 #e9f2ed 到 #f4f7f3 的柔和径向渐变，裁切舞台外的装饰。
舞台下方标题为“层叠之间”，16px 中等字重；副标题为“The card choreography”，10px、颜色 #a0a7a2。舞台左上显示 NO. 01，右上显示“时间轴”，用低对比度小字。
四张内部卡片宽 min(174px, 舞台宽度减40px)、高 110px、13px 圆角。每张使用 1px 半透明白边和 0 9px 20px #24332b18 阴影。四张的背景与文字颜色依次为
绿色 linear-gradient(135deg,#e7f3ec,#c7e0d3)，文字 #254b3b。
蓝色 linear-gradient(135deg,#e7eff9,#c8d9ec)，文字 #294760。
紫色 linear-gradient(135deg,#eee9f6,#d9cde9)，文字 #514265。
米色 linear-gradient(135deg,#f5eddc,#e5d4b4)，文字 #624e2e。
面内留 16px 至 19px 内边距，上方写 STUDY / 01 等编号，主标题 25px，右下用简单几何符号装饰。把负责姿态的外层与负责纸张表面的内层分开。

运动坐标与术语
使用 requestAnimationFrame 驱动时间轴，ref 保存时钟和当前姿态，不在每帧调用 React setState。pose 是 [x,y,angle]，单位为 px、px、deg。先把卡片锚点放在舞台中心向左 8px，再用 translate(-50%,-50%) 将卡片自身居中，然后叠加 pose。
四个从前到后的叠放姿态 P0、P1、P2、P3 为 [-13,17,-7]、[0,5,0]、[12,-5,7]、[24,-15,14]。
index 表示当前前卡编号。第 i 张卡当前的 slot=(i-index+4)%4，slot=0 是前卡。

阶段时间轴
逻辑循环为 5770ms，仅累计允许播放且没有展开时的时间。
0至3000ms 为 hold，四张保持起始叠放姿态。
3000至3180ms 为 prepare，继续保持姿态。
3180至4080ms 为 extract，前卡从 P0 向左抽出。
4080至4575ms 为 lower，旧前卡在左侧下沉，其余三张补到前一层。
4575至5430ms 为 return，旧前卡回到 P3，成为最后一张。
5430至5590ms 为 settle，保持终点。
5590至5770ms 为 hide，仍保持终点，不额外让整个卡面消失。循环结束后 index=(index+1)%4，所有卡片首尾位置必须连续。

路径计算
设卡片宽 w、高110，旋转角 a 的水平半包围盒 half(a)=(w*abs(cos(a*PI/180))+110*abs(sin(a*PI/180)))/2。
计算 exitX=min(Pj.x-half(Pj.angle))-half(-7)-18。抽出终点为 [exitX,17,-7]，下沉终点为 [exitX,26,-7]，这样卡片会先绕到卡堆左侧再回去。抽出过程中允许图形被舞台左边缘部分裁切。
移动总进度 p=(elapsed-3180)/2250，限制在0至1。前卡在 p=0至0.4 从 P0 到抽出终点，0.4至0.62 到下沉终点，0.62至1 回到 P3。其他卡在0.4至0.62从 Pslot 移到 P(slot-1)。
每一小段先把局部进度 t 夹取到0至1，再用 smootherstep(t)=6t^5-15t^4+10t^3 缓动。lerp(a,b,t)=a+(b-a)*t，逐项插值 x、y、angle。
p<0.4 时层级 z=4-slot；p>=0.4 时旧前卡 z=1，其余卡 z=5-slot。回程开始前只有旧前卡的文字目标可见，从 return 开始改为下一张前卡的文字目标可见。文字可用 opacity、7px 位移和4px模糊过渡，避免两张文字长期重叠。

展开交互
展开为两行两列，左右列分别旋转 -4deg 和4deg，间隙12px。计算旋转后的宽 rw=w*cos(4deg)+110*sin(4deg)，高 rh=110*cos(4deg)+w*sin(4deg)。
舞台尺寸为 W、H，scale=min(0.7,(W-36)/(2*rw),(H-20)/(2*rh))。列偏移为 ±(rw*scale+12)/2，行偏移为 ±(rh*scale+12)/2；对应 pose 的 x 再加8以抵消前面的锚点偏移。展开时四张文字都可见，卡片不得互相遮住或越界。
进入和退出展开时，从当前姿态逐步靠近目标，采用 alpha=1-exp(-deltaMs/80)，约600ms完成收束。收束期间不推进轮转时间。收回后从当前前卡的 hold 重新开始。
支持鼠标进入与离开、Tab 聚焦与失焦，以及 Enter、空格、触摸点击。避免一次触摸同时触发 focus 和 click 导致连续切换两次。缩放尺寸变化时重新测量舞台。

本动画额外验收
对四个 index 采样整轮时间，检查坐标有限、层级不冲突、叠放时只有一张文字目标可见；检查5770ms交接的几何连续，以及两列展开在窄屏仍留出间隙。

播放与可访问性
在舞台左下角放两个独立按钮，分别控制暂停或继续、从头重播。按钮尺寸至少 32px，有中文 aria-label 和清晰的键盘焦点，按钮自身不要跟随内部图形运动。
初始进入页面即可看到完整构图。使用 IntersectionObserver 观察舞台，露出比例达到 0.08 时才允许自动播放，并结合 document.hidden 和手动暂停状态共同控制。切到后台或离屏后停止主要循环，回来时只在手动暂停未开启的情况下恢复。
CSS 动画通过 animation-play-state 暂停，覆盖普通元素和伪元素；JS 时间轴取消 RAF；播放器使用自身暂停接口。恢复时重置上一帧时间戳，避免把后台停留时间算进动画。
监听 prefers-reduced-motion。开启时停止装饰性循环与跟随位移，展示清楚的静态构图；必要的展开或切换可以立即完成。任何 Effect 都要清理监听器、观察器和待执行的回调，确保 React StrictMode 的重复创建与清理安全。

完成后的验收
检查 320px、768px、1440px 宽度，页面没有横向滚动，标题和按钮不被动画遮住。分别检查首次加载、循环接缝、暂停继续、重播、离屏返回和静态模式。
验证同页两个实例互不影响，卸载后没有继续运行的时间轴或播放器。运行 npm run build，报告执行结果；无法运行的检查写明未执行。最后用短说明解释关键帧、坐标与交互之间的关系。
```
