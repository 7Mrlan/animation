# 第 09 章 一封轻盈的信怎样用 CSS 拼出来

这张卡片只需要信封主体和一枚标签。信封上面的折角、下面的封口都由伪元素画出。它是本项目最适合从头重做一次的例子。

打开 [FloatingMail.tsx](../../src/animations/FloatingMail.tsx) 和 [FloatingMail.css](../../src/animations/FloatingMail.css)。读完以后，你应该能够在不增加图片资源的情况下，画出信封并让两部分反向浮动。

## 先看静态信封

主体是一个 170 × 94px 的圆角矩形。边框颜色略深，背景略浅，`overflow: hidden` 把超出矩形的部分裁掉。

两个伪元素都是 124 × 124px 的方块，旋转 45 度。上方方块的 top 为 -82px，下方方块的 top 为 48px。它们大部分位于主体外侧，裁切以后，只留下组成折角和封口的斜边。

调试时可以临时取消主体的 `overflow: hidden`，就能看见完整的方块。确认形状怎样拼成以后，再恢复裁切。这个动作比直接盯着几十行 CSS 猜结构更容易理解。

## 阴影和边缘分别负责什么

主体的外阴影向下偏移 10px、模糊 20px，使用很低的透明度。它让信封与背景分开，但没有把周围染成一大片深色。伪元素自己的细边框则负责表示折线。

标签又有独立的边框与较小阴影。因此它看起来像叠在信封前面的另一张纸，不需要增加大幅度的运动才能让人分辨。

修改质感时，可以先调整边框明暗，再比较阴影。只增大阴影往往会让卡片显脏，尤其在这里的浅色背景上。

## 两个动作共用周期

| 元素 | 周期起点与终点     | 周期中点             |
| ---- | ------------------ | -------------------- |
| 信封 | y 为 0，旋转 -6 度 | 上移 7px，旋转 -3 度 |
| 标签 | y 为 0，旋转 5 度  | 下移 3px，旋转 8 度  |

周期都是 5s，缓动都是 `ease-in-out`。一个向上，一个向下，改变了它们的相对距离。中点时，仅看纵向位移这一项，相对差值为 10px；旋转还会改变边缘的视觉位置。

```css
@keyframes store-envelope-float {
  0%,
  100% {
    transform: translateY(0) rotate(-6deg);
  }
  50% {
    transform: translateY(-7px) rotate(-3deg);
  }
}
```

首尾的数值一致，循环回到第一帧时不会因为位置不同突然跳一下。两段运动都不需要组件状态，也没有 JS 定时器。

## 标签的定位与浮动分开看

标签当前定位在 `top: calc(50% + 15px)`，水平方向位于 `left: calc(50% + 14px)`。这决定它在舞台中放在哪里；关键帧中的 3px 位移再叠加到这个基础位置上。

文件前部仍保留较早的高度和标签 top 声明，后面的同等优先级规则会覆盖它们。读抽离代码时，找到第一个同名选择器以后还要继续往下看。浏览器的计算样式可以帮助确认最后生效的值。

## 暂停与静态是两种结果

画廊手动暂停时，CSS `animation-play-state` 会让动画停在当前时间。系统减少动态效果时，本动画的媒体查询会移除动画，回到基础姿态，信封与标签仍完整显示。

基础 transform 已经给了角度，因此去掉关键帧以后，静态图形不会突然全部变成水平摆放。制作其他动画时，也应当先有一个能独立成立的静态姿态。

## 练习增加统一的幅度控制

把上移 7px、下移 3px 和角度变化分别变成变量，再用一个 `amplitude` 参数统一缩放它们。默认 1 保持原样，0.5 减半，0 不产生位移与角度变化。

实现时保留信封的 -6 度和标签的 5 度基础角度。幅度为 0 只关闭变化量，不应把整张信封强制摆正。

从空目录生成同款效果，可复制[独立生成提示词](../prompts/09-floating-mail.md)。下面的提示词用于本项目内的修改练习。

```text
请阅读 src/animations/FloatingMail.tsx 和 FloatingMail.css。
增加 amplitude 参数，默认 1，用 CSS 变量控制位移和旋转变化量。
信封仍以 -6deg 为基础，标签仍以 5deg 为基础；5s 周期保持原值。
amplitude 为 0、0.5、1 时，变化量应分别关闭、减半和保持现状。
保留伪元素折角、边框和阴影，不增加图片或依赖。
运行 npm run build，检查三个参数值与减少动态效果，并说明是否完成浏览器验证。
```
