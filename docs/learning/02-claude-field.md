# 第 02 章 灵感引力场的多层运动

把指针慢慢移向卡片右边。背景亮区会跟过去，中央标志只移动一小段，纸片和细线仍按自己的节奏运动。这个例子适合学习怎样让几个简单动作共存，又能看出主次。

对应代码是 [ClaudeField.tsx](../../src/animations/ClaudeField.tsx) 和 [ClaudeField.css](../../src/animations/ClaudeField.css)，还需要本地的 [Claude SVG](../../public/brands/claude.svg)。

## 先把画面拆成可见的层

最底层是暖色径向渐变和网格。上面有呼吸的圆形亮区、三张纸片和两条椭圆细线。标志位于中间偏上的绘制层，节点和文字再盖在前面。

`z-index` 为这些元素安排遮挡次序。读代码时可以暂时给纸片加一圈明显的轮廓，确认它到底压住了谁，再撤掉调试样式。大量半透明元素叠在一起时，单看颜色不容易判断顺序。

## 指针坐标怎样交给 CSS

组件将容器左上角作为原点，把指针位置转换成百分比。

```ts
x = ((event.clientX - rect.left) / rect.width) * 100
y = ((event.clientY - rect.top) / rect.height) * 100
```

`pointer` 初始为 `{ x: 50, y: 50 }`，对应舞台中心。离开容器时也恢复到这个位置。这里使用 React state，每次更新都会让组件重新渲染，随后把百分比写成 `--claude-x` 和 `--claude-y`。

这个版本没有额外把数值限制到 0 至 100，也没有 RAF 合帧。它保留了易读的原始写法。需要处理更多实例或极密集事件时，可以参考[代码微光](04-code-workspace.md)的实现。

## 光晕跟随，标志只移动一点

背景渐变直接把百分比坐标作为圆心。另一个直径为 150px 的光圈用 `left = x - 75px`、`top = y - 75px`，让圆心对准指针。

中央标志使用较小的跟随比例。

```css
left: calc(50% + (var(--claude-x) - 50%) * 0.12);
top: calc(50% + (var(--claude-y) - 50%) * 0.12);
```

指针从中心移到右边缘，标志的定位值从 50% 变为 56%。在 360px 宽的舞台上，水平变化约为 21.6px。它仍接近中心，光圈则跟得更远，画面因此产生前后距离感。

标志本身通过 CSS mask 使用 SVG 轮廓，填色来自 `currentColor`。替换图形时，要一起检查遮罩路径和新图形的可见面积。

## 为什么各层不会一起起落

| 元素     | 当前周期  | 主要动作                       |
| -------- | --------- | ------------------------------ |
| 纸片 a   | 4.4s      | 上移约 8px，并改变角度         |
| 纸片 b   | 5.3s      | 使用反向关键帧                 |
| 纸片 c   | 6.1s      | 延迟 0.6s 开始                 |
| 两条细线 | 7s 与 10s | 旋转，第二条反向               |
| 节点     | 2.7s      | 缩放和透明度变化，延迟各不相同 |
| 标志阴影 | 4.2s      | 改变投影距离和模糊             |

这些周期独立，移动指针不会重置它们。标志悬停时还会旋转到 6 度并放大到 1.08，日常循环只改变它的滤镜，两者没有争写同一个属性。

纸片有一个适合练习读样式的细节。普通规则中写了某些旋转和缩放，运行中的关键帧也写 `transform`。默认的动画合成采用替换，同一属性不能简单按两行声明相加。纸片 b 的静态缩放因此不能直接当成整个循环的最终缩放。如果要固定缩小纸片，同时让它上下漂浮，可以把缩放放到外层，动画放到内层。参见 [MDN animation-composition](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/animation-composition)。

## 调得更安静，先减哪一项

先把标志的跟随系数从 0.12 降到 0.08，保留光圈位置。读者仍然看得出指针参与了动画，中央图形的摆动会小一些。之后再比较纸片的 8px 上移是否需要减小。

不要一次同时改颜色、周期和位移，否则很难解释改善来自哪里。复制到别的项目时，还要保留动画容器的定位和尺寸，遮罩路径也要能正确解析。

从空目录生成同款效果，可复制[独立生成提示词](../prompts/02-claude-field.md)。下面的提示词用于本项目内的修改练习。

