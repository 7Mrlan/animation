# 第 08 章 小小宇宙的伪元素与颜色变量

两条椭圆线、两颗小圆点和一个中心方块，就组成了这张卡片。它适合学习怎样复用一组动作，同时让调用方改变配色。

对应文件是 [OrbitCore.tsx](../../src/animations/OrbitCore.tsx) 和 [OrbitCore.css](../../src/animations/OrbitCore.css)。组件目前提供固定的 `--catalog-hue` 与 `--catalog-bg`，还没有把它们公开成 props。

## 少量 DOM 怎样画出多层内容

容器的 `::before` 和 `::after` 负责两条轨道。两个 `.store-art-orbit` 元素负责圆点，`.store-art-core` 负责中心方块。标签与竖排文字只做装饰。

伪元素需要 `content: ''` 才能生成盒子。它们绝对定位在容器内，用椭圆边框画线，不需要为每条轨道增加一个真实元素。

中心方块用 `z-index: 2` 放在前面，根容器的 `isolation: isolate` 为这一组内容建立独立的堆叠上下文。这样思考绘制顺序时，可以先在这张卡片内部比较层级。

## 轨道做的是往返摆动

`catalog-orbit` 从 -18 度转到 -10 度，同时向上移动 5px，再回到起点。第一条轨道周期为 6s，第二条为 8s 并使用 reverse。它们都没有连续绕完整一圈。

由于这组关键帧的首尾相同，而且中点两侧对称，反向播放未必带来明显的相反运动感。画面差异主要还来自尺寸、周期和起始位置。若要明显表达两条线朝相反方向转动，可以参考 Gemini 的整圈旋转。

第二条轨道的普通规则还写了 `rotate(42deg)`，但运行时关键帧会接管它的 transform。要保留固定倾角，再叠加摆动，需要统一写入关键帧，或用不同元素分别承载。这是一个很适合检查计算样式的地方。

## 方块与粒子用不同节奏

中心方块的周期为 4.5s。它在 -6 度与 -2 度之间转动，缩放从 1 到 1.04，纵向位移从 -50% 到 -53%。方块高 78px，这部分位移差约为 2.34px。

圆点的幅度更明显，关键帧让它们上移 12px，放大到 1.12。两个周期分别为 4s 和 5.4s，尺寸也分别为 18px 与 9px。较小的元素可以承担稍活跃的动作，中心方块仍然保持稳定。

## 一份颜色怎样传给多个部件

根容器的文字颜色由 `hsl(var(--catalog-hue) 36% 30%)` 计算。边框和圆点使用 `currentColor`，会跟着继承来的颜色变化。

背景和中心卡片又用到了 `--catalog-bg`。例如方块背景把该颜色与白色混合，边框和阴影则把当前颜色与透明色混合。调用方换色时，相关部分因此能一起变化，不必逐个寻找十六进制颜色。

```tsx
import type { CSSProperties } from 'react'

const sceneStyle = {
  '--catalog-hue': '200',
  '--catalog-bg': '#e9f0f5',
} as CSSProperties
```

这里单独列出了组件传给 style 的配色对象。把它变成参数时，仍要检查对比度。共享颜色让调整方便，但无法自动保证文字、边框在所有背景上都清楚。

## 改高度时，先找固定坐标

当前根容器高度为 100%，但轨道仍使用 `top: 39px`、`56px`，圆点也有固定 top。改变舞台高度后，中心方块会跟着百分比居中，轨道不一定同幅移动。

因此，“支持任意高度”不能只靠根元素的 `height: 100%`。若要做成真正随舞台中心布局的组件，需要重新定义这些固定坐标与中心的关系。

## 练习公开配色参数

增加 `hue` 与 `background` 两个可选参数，保留当前默认值。让同一页出现蓝色与暖色两个实例，观察圆点、方块边框和阴影是否随各自的父容器变化。

```text
请阅读 src/animations/OrbitCore.tsx 和 OrbitCore.css。
增加可选的 hue 与 background 参数，默认值保持 200 和 #e9f0f5。
继续通过组件根元素的 CSS 自定义属性传值，保持 currentColor 的复用方式。
两种配色实例需要互不影响，现有轨道、粒子和中心方块的动作保持原样。
不要改成 Canvas，不新增依赖。
检查浅色背景下的辨识度和静态模式，运行 npm run build，并给出两个调用例子。
```
