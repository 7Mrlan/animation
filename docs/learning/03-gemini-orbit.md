# 第 03 章 星光慢行的反向轨道

这张卡片没有指针跟随。中央星形缓慢浮动，两圈轨道反向旋转，小星点按错开的节奏明灭。它适合练习把形状、位置和时间分开处理。

打开 [Membership.tsx](../../src/animations/Membership.tsx) 中的 `GeminiMark`、`GeminiOrbit`，并对照 [Membership.css](../../src/animations/Membership.css)。同一文件还包含 Duo 组件，改样式时要选中 `.gemini-*` 相关规则。

## 星形来自 SVG 路径

SVG 使用 `viewBox="0 0 160 160"`。路径沿四个方向向外延伸，中间的曲线向中心收拢。轮廓由 `path` 决定，蓝紫到粉色的填充由 `linearGradient` 决定。

`useId()` 为每个组件实例生成不同的渐变 ID。`fill` 再通过 `url(#id)` 引用它。同页放多个星形时，如果每个都写相同 ID，浏览器可能引用到另一个实例的渐变。这里已经把实例区分开了。

想换颜色，先改三个 `stopColor`。想换轮廓，才需要修改路径。把两件事分开，可以避免为了换色误改形状。

## 轨道上的点为什么会绕着走

内圈宽 190px、高 96px，外圈宽 240px、高 146px。它们都用边框和 `border-radius: 50%` 画成椭圆。小圆点是轨道自己的 `::after`，位置固定在轨道内部。

旋转轨道时，伪元素会随父元素一起旋转，所以不需要额外计算小圆点的 x、y。这个版本表现的是整个椭圆连同圆点一起转动。若希望椭圆保持静止，只让点沿椭圆移动，就需要换一种结构或路径算法。

两个轨道共用 18s 周期，外圈设置 `animation-direction: reverse`。关键帧终点为 330 度，普通规则提供的起点为 -30 度，相差正好一圈，首尾能接上。

## 星形浮动里藏着几种变化

| 项目     | 循环起点和终点 | 中点 |
| -------- | -------------- | ---- |
| 垂直位移 | -50%           | -57% |
| 旋转     | -6deg          | 6deg |
| 缩放     | 0.97           | 1.05 |

这一轮用 7 秒完成。星形盒子高 105px，垂直位移增加的 7 个百分点约为 7.35px。缩放和旋转还会影响最终视觉轮廓，所以画面占用范围要实际检查。

星点的周期为 4 秒。第二个星点带有 `-2s` 延迟，相当于从周期中途开始播放，加载后就能看到错开的状态。负延迟的含义可查 [MDN animation-delay](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/animation-delay)。

## 有些名字相近，动作却不同

`gemini-orbit` 会完整转一圈，第 08 章的 `catalog-orbit` 只在两个角度之间来回摆动。给 AI 写要求时，明确写“连续旋转一圈”或“在两个角度之间往返”，比只写“轨道动画”可靠。

这里的 `.membership-visual` 没有入场淡入。它保持静态首帧可见，避免用户暂停后再筛选到这张卡片时，内容停在透明的第一帧。

## 把三种节奏分开练

先把两圈旋转周期从 18s 改为 24s，星形浮动仍为 7s，星点仍为 4s。观察轨道变慢后，中央图形是否更突出。然后恢复，再只改星点透明度。

如果两张 Gemini 卡片同时展示，检查各自的 SVG 渐变仍有效。最后打开系统减少动态效果，确认星形和轨道保留完整静态外观。

从空目录生成同款效果，可复制[独立生成提示词](../prompts/03-gemini-orbit.md)。下面的提示词用于本项目内的修改练习。

```text

星形的 7s 浮动、星点的 4s 闪烁和 -2s 延迟不变。
修改不得影响同文件中的 DuoScene，不添加新依赖。

```
