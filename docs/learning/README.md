# 动画卡片学习手册

打开任意一张动画卡片，先看它怎么动，再打开旁边的源码。这本手册带你把看到的动作找到对应的代码，改一个参数，观察结果，最后把需求写成 AI 能执行、自己也能验收的提示词。

读者需要认识 HTML 元素，能读懂 CSS 选择器，并了解 JavaScript 函数。React 部分会解释当前动画用到的 Hook。暂时不懂三角函数也可以先学信封和消息气泡，卡片轮转放到后面。

正文中的文件、参数和行为按本项目 `4b9920c` 版本核对。标为练习的修改尚未包含在应用中，可以在自己的分支尝试。

## 每次练习只改变一件事

先录下一轮动作，或者在浏览器动画面板里暂停观察。接着只改位移、周期、延迟中的一个参数。看清它造成的变化以后，再组合调整。

动画章节末尾的提示词用于本仓库内的修改练习。若要交给没有项目上下文的 AI，从空目录生成动画，使用[动画生成提示词库](../prompts/README.md)。其中九份写明已有动画的完整规格，另外四份用于新商品与产品元素的创意生成，都不需要先提供源码。
