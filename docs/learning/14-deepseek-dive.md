# 第 14 章 潜入答案：拖拽、巡游与鲸跃

第 10 张卡片是本画廊新增的 DeepSeek 动画。[组件](../../src/animations/DeepSeekDive.tsx)负责 SVG 与唯一 ID，[场景控制器](../../src/lib/deepseek-scene.ts)负责输入和绘制，[运动模型](../../src/lib/deepseek-motion.ts)规划路径，[水面模型](../../src/lib/deepseek-water.ts)传播冲击。

## 图形与水流

原始参考为 DeepSeek 官方仓库的小鲸 SVG，七张角色关键姿态通过离线运动补间扩展为 241 帧本地图集。图集上半部是身体，下半部是互补尾部；每个姿态绕自身尾柄摆动，身体重心保持对齐。转身使用临界阻尼的连续位置与角速度，依次经过斜侧与背面，中途反向不重启动画，暂停不推进帧号。requestAnimationFrame 按屏幕刷新更新，20、60、120Hz 下转身时长保持一致；素材帧数不等于设备实际显示帧率。`useId` 隔离水面与鱼虾的实例引用。ResizeObserver 更新舞台尺寸，绘制时抵消横纵缩放差，鲸鱼不会随卡片变宽而变胖。

海面由长涌浪、短风浪、浪群包络和 61 个局部弹簧节点构成。阵风平滑增强再消退，较强时偶尔吹散少量浪尖飞沫。鲸鱼的排水压力和入水冲击传给邻点，端点阻尼吸收传播能量；每步最长约 8ms。一次采样供分层水体、遮挡和裁切共用，以二次曲线平滑绘制。深浅渐变与浪峰反光提供水体层次，水下流纹和气泡始终裁切在水中。这里是适合小卡片的二维风格化水面，不是三维流体求解器。

## 拖拽与浪花

透明按钮是可聚焦的拖拽目标，使用 transform 跟随。`setPointerCapture` 保证拖出按钮后仍能收到释放事件。指针转换成 360×300 的舞台坐标，位置立即更新，水面接触和绘制在下一帧统一处理。低速轻拖不喷溅，穿水速度和靠近水面的移动速度决定浪花强度。甩动速度经过短时间滤波，按住不动后松手不再继承过期速度。水滴最多同时保留 72 个，气泡最多 18 个，过期节点归还池供后续复用。

## 巡游与鲸跃

运动状态是不可变快照。深潜、浅游、绕弯与蓄力通过受限加速度追踪目标点，保留换段速度；软边界提前引导转弯。最长 1/120 秒积分子步使 20、60、120Hz 下的时间推进一致。身体俯仰使用显示坐标下的速度方向，摆尾频率随游速变化；上浮换气时按剩余上浮距离加强摆幅，到位后再减弱推进。

鲸跃先下潜到准备区，再转入摆尾蓄力和持续上冲；发射方向在准备时确定，不因中途横移越过卡片中心重新翻转。完全离水后只受重力，出水速度预算受上方空间限制，甩动的预测飞行横移限制在 28 个舞台单位以内。首次接触水面产生一次冲击事件，记录减速前的法向速度与接触面积，以速度平方映射短促水帘、两侧破水飞沫、水冠、局部传播波和三层扩散水纹；较高鲸跃留下更宽、更久的余波。浸没比例决定浮力与二次水阻，消耗下坠动量后顺势潜游，不要求先朝上反弹。双击与空格邀请在准备、蓄力和腾空期间保持幂等。

[独处意图](../../src/lib/deepseek-solo.ts)按当前水深、动量、边缘余量和上一动作加权采样，事件之间留出约 6–12 秒空档。推进后短滑、独处短冲、贴水露背、下潜、探头、小幅侧身弧游、轻拍尾和浮休使用不同的目标与尾部用力。滑行只在已有足够前向动量和余量时开始；水面动作提前反向，不持续顶在软边界。浮休先游到水面，才降低尾摆并显示呼吸起伏、漂移和 Zzz；上浮失败则继续巡游，醒来先恢复推进再下潜。姿态和尾摆强度保留连续权重。露背换气不淡化全身：水下身体与水上背鳍共用互补的动态水线裁切，背鳍随高度逐渐露出，转向沿连续偏航变化；身体接近水面后放平，换气、短滑和俯头下潜属于同一航段。追逐打断后也先保留遮挡，整身沉回水线后才解除，避免旧尾鳍突然弹出；已发出的气雾自然消退，不重复呼气。小幅侧滚使用轮廓遮罩内的腹侧显露与轻微透视缩短，和左右转身进度独立；属于二维投影表现，不是完整三维模型。

## 鱼虾与追逐

[遭遇模型](../../src/lib/deepseek-prey.ts)按随机时间生成小鱼或小虾群。每个实例由 `crypto.getRandomValues` 初始化种子，入场方向、深度、数量、大小与个体偏移均重新采样；测试则显式传入种子以复现。鱼群为 20–36 只，虾群为 7–17 只，首群延迟 8–20 秒，群体之间保留随机空档。鲱鱼群有较长的入场队形，平游时增强聚合和对齐，受威胁时局部散开。

鲱鱼共享有限转弯速率的宽弧迁移意图，邻域分离、对齐和聚合修正个体位置。局部警戒经邻居传递，巡游、受惊加速、短冲刺与恢复有独立节奏；共享航向使用群体平均警戒，单个受惊者不会立即让全群掉头。群体根据鲸鱼的预测拦截位置比较前后与上下的空间，选择绕行、回身或换层，动作有保持期，散开后逐步加强对齐和聚合，近处仍有危险的个体继续逃逸。入场者在进入追逐区前已感知鲸鱼并改变深度，保持同一绕行侧和向内速度，避免送到嘴边或左右弹动。入场状态只执行一次。卡片下缘是视野边缘，猎物可以向下逃出；鲸鱼不继续锁定不可达深度的个体。最后一只离场后再等待随机空档，长时间遭遇不会导致下一群立即补位。

鲸鱼锁定可达内区的猎物，预判短期位置，避免逐帧重选最近者。普通跟随接近目标时减速，解决越过目标反复掉头的问题；对准猎物且有足够空间时则进入短促的捕食冲刺，期间保持攻击线路，不套用接近减速。追逐目标速度最高约 94，短冲约 144 个舞台单位/秒，左右均按实际可用空间缩短攻击距离。同一次吞食可收拢多个个体，连续接触不反复重置恢复计时；吞食期间已观察下一目标，窗口结束后恢复追击。吞食后增加减速并保留前向滑行；尾摆幅度和频率共同响应推进强度，尾迹记录最近 0.42 秒的真实路径。实际靠近嘴部才触发收拢淡出；没有被捕食的个体必须游出卡片才移除。有活跃猎物时立即退出可中断的独处动作与自动蓄力，即使猎物还在入口尚不可锁定，也延后自动鲸跃；已腾空则先安全入水。捕食期间空格和双击邀请也让位于猎物，拖拽与甩动仍保留直接操控。取食运动时序参考 [Simon 等 2012](https://pubmed.ncbi.nlm.nih.gov/23053368/)，卡片内的时长与速度经过视觉缩放。

造型以太平洋鲱鱼与磷虾的结构为参考：鲱鱼背暗腹亮，保留鳃盖、背鳍、细尾柄与分叉尾；小虾保留头胸甲、分节腹尾、大圆眼和细触须，配色借鉴海水火焰虾的红色身体、白斑和浅色触须，提高小尺寸下的辨识度。这是风格化配色，并不把真实珊瑚礁清洁虾描述为大洋群游猎物。部件分别通过 SVG use 引用，共享节点池。磷虾的迁移意图允许改变深度与横向方向，局部对齐与聚合对上下邻居更敏感；近距离直接威胁立即触发短促尾弹，邻居警戒逐步传递，尾弹结束后有恢复期。身体朝向与速度分离，因此能后退逃逸；平游恢复腹下附肢划动。游姿只读取模拟时钟，暂停时不会继续摆尾。

群体规则的证据边界：太平洋鲱鱼的强集群性参考 [NOAA](https://www.fisheries.noaa.gov/species/pacific-herring/management)；分级威胁与集体下潜机制参考[大西洋鲱鱼实验](https://pubmed.ncbi.nlm.nih.gov/24489778/)，不照搬为太平洋鲱鱼的精确参数。磷虾的上下协调与邻居速度调整参考 [Burns 等 2022](https://pubmed.ncbi.nlm.nih.gov/35193400/)，短促后向尾弹参考[南极磷虾流体动力学研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10068603/)。动画里的评分、秒数与转向率是二维卡片的设计参数；不是训练出的智能，也不代表精确生物仿真。

行为参考：[NOAA 须鲸取食](https://www.fisheries.noaa.gov/species/humpback-whale/science)、[Reynolds steering](https://www.red3d.com/cwr/steer/gdc99/)、[须鲸冲刺取食运动研究](https://journals.biologists.com/jeb/article/223/20/jeb224196/226006/Lunge-filter-feeding-biomechanics-constrain)。这些行为被缩放为卡片内的风格化互动，不代表品牌图形的精确物种模型。

## 播放与清理

`setPlaying` 停掉 RAF，保留姿态与时钟；恢复重置上一帧时间戳。`dispose` 取消 RAF、通过 AbortController 撤销监听器、释放捕获并清理粒子。静态模式没有自动游动、波浪和粒子，拖动与方向键仍可直接摆放小鲸，空格在两个静态位置切换。画廊重播会重建实例。

练习：只把首次自动鲸跃的最早等待从 6.8 秒改成 8 秒，保留后续约 25–39 秒的休息时间；独处动作和猎物仍可延后实际起跳。运行 `npm run check`，再确认连续邀请不会重置蓄力、暂停不推进时钟、落水不强制上浮、正常巡游不碰硬边界，以及有猎物时不会新开独处动作或自动鲸跃。
