# 第 14 章 潜入答案：拖拽、巡游与鲸跃

第 10 张卡片是本画廊新增的 DeepSeek 动画。[组件](../../src/animations/DeepSeekDive.tsx)负责 SVG 与唯一 ID，[场景控制器](../../src/lib/deepseek-scene.ts)负责输入和绘制，[运动模型](../../src/lib/deepseek-motion.ts)规划路径，[水面模型](../../src/lib/deepseek-water.ts)传播冲击。

## 图形与水流

鲸鱼来自 DeepSeek 官方仓库的本地 SVG。两块互补 clipPath 分别显示身体和尾巴，尾巴绕连接处旋转；`useId` 隔离每个实例的引用。水面由移动的正弦波、73 个弹簧采样点、分层填色和白色流纹构成。冲击传给邻点，阻尼让浪逐渐衰减，每步最长约 8ms。采样点转成连续贝塞尔曲线绘制。

## 拖拽与浪花

透明按钮是可聚焦的拖拽目标。`setPointerCapture` 保证拖出按钮后仍能收到释放事件。指针转换成 360×300 的舞台坐标，位置立即更新，下一帧统一绘制。入水和出水产生冲击，水面附近移动越快浪花越强，超过上限则保持最大强度。水滴按速度、重力和寿命更新，最多保留 96 个，回到水里后清理。

## 巡游与鲸跃

水下使用三次贝塞尔曲线，交替经过深潜、浅游和绕弯。身体俯仰根据速度计算，摆尾频率随游速变化。鲸跃先沿曲线上浮蓄力，再使用重力抛物线：根据约 64 单位的最高点计算初速度，下降入水后激起大浪花，接回深潜。巡游中间隔触发，也支持双击、空格和向上轻甩松手。

## 播放与清理

`setPlaying` 停掉 RAF，保留姿态与时钟；恢复重置上一帧时间戳。`dispose` 取消 RAF、通过 AbortController 撤销监听器、释放捕获并清理粒子。静态模式没有自动游动、波浪和粒子，拖动与方向键仍可直接摆放小鲸，空格在两个静态位置切换。画廊重播会重建实例。

练习：只把首次自动鲸跃的等待从 5.1 秒改成 7 秒，保留后续 8.5 至 12.5 秒的休息时间。运行 `npm run check`，再确认双击仍可提前触发，暂停期间不推进等待时间。
